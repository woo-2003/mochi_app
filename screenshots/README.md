3. **map_screen.png** - 지도 화면 (메인 화면)

4. **chat_list_screen.png** - 채팅 목록 화면

5. **chat_screen.png** - 채팅 화면
   - 메시지 말풍선들 (내 메시지: 오른쪽, 상대 메시지: 왼쪽)

6. **friends_list_screen.png** - 친구 목록 화면
   - 3명의 친구 카드 (미소, 성결, 공대)
   - 각 카드에 프로필 이미지, 이름, 상태 메시지, 위치 아이콘

7. **profile_screen.png** - 마이페이지/설정 화면

## 이미지 저장 방법

1. 앱을 실행하고 각 화면으로 이동
2. 스크린샷 캡처 (Android: 볼륨 다운 + 전원 버튼, iOS: 홈 버튼 + 전원 버튼)
3. 이미지를 위의 파일명으로 저장하여 `screenshots/` 폴더에 넣어주세요

## 참고사항

- 이미지 해상도: 최소 1080x1920 (Full HD) 권장
- 파일 형식: PNG (투명도 지원)
- 파일명은 정확히 위와 같이 작성해주세요 (대소문자 구분)
